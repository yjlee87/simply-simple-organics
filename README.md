# Simply Simple Organics 产品目录

纯静态网页：产品资料都在 `products.json`，图片在 `images/`。改完推上去，网站就更新了。

## 打开

```bash
python3 serve.py
```

然后打开 <http://localhost:4173>。

## 部署

在 Vercel 里 Add New → Project，导入这个仓库，什么都不用设置，直接 Deploy。
之后每次推送到 `main`，网站会自动更新。

## 改资料

### 店铺信息（`products.json` 顶部的 `store`）

| 字段 | 说明 |
| --- | --- |
| `name` | 店名，显示在页面顶部 |
| `tagline` | 店名下面的一行小字 |
| `currency` | 价格前的货币符号，例如 `RM`、`¥`、`$` |
| `whatsapp` | 询价用的 WhatsApp 号码，带国家码、不要 `+` 和空格，例如 `60123456789`。留空就不显示询价按钮 |
| `note` | 页脚说明 |

### 产品（`products` 列表，每个产品一条）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✓ | 产品编号，用 JUNE-25 价目表的货号，不能重复。也是详情页链接：`/#HUY0001`。同一货号分男女款时加 `-F` / `-M` |
| `sku` | | 卡片和详情页上显示的货号，不填就显示 `id` |
| `name` | ✓ | 产品名称 |
| `price` | ✓ | 价格，写数字，例如 `39.9` |
| `category` | | 分类，页面顶部的分类按钮按这个自动生成 |
| `summary` | | 一句话介绍，列表里显示 |
| `description` | | 详细介绍，详情页里显示，`\n` 换行 |
| `specs` | | 规格表，`{ "尺寸": "30 × 20 cm", "材质": "不锈钢" }`，想加几行加几行 |
| `images` | | 图片路径列表，**第一张是主图**，后面是细节图 |
| `originalPrice` | | 原价，填了会显示划线价 |
| `tags` | | 标签，第一个显示在卡片角上，例如 `["新品"]` |
| `soldOut` | | 写 `true` 显示售罄 |

JSON 格式要求严格：最后一项后面不能有逗号，文字要用英文双引号。改完页面空白的话，
多半是格式错了，可以贴到 <https://jsonlint.com> 检查。

## 放图片

每个产品一个文件夹，名字和 `id` 一样（货号里的空格、斜杠换成 `-`）：

```
images/HUY0001/main.jpg
images/HUY0001/detail-1.jpg
images/HUY0001/detail-2.jpg
```

- 建议用正方形、长边 1200–1600px 的 JPG 或 WebP，单张 300 KB 以内，手机上打开才快。
- 文件名用英文和数字，不要有空格。
